# ONE SHOT v6.6.7 · Mobile Batch Classifier

## Objetivo
Mantener el celular enfocado en captura y clasificación rápida de evidencia política, conservando Excel y sincronización como salidas operativas mientras se desarrolla ONE SHOT Operaciones.

## Flujo
1. Evidencias -> Seleccionar.
2. Marcar las evidencias a trabajar.
3. Clasificar lote.
4. Para cada evidencia: foto -> organización -> tipo -> empresa solo si PANEL.
5. Guardar y avanzar, repetir la clasificación anterior, saltar o marcar para revisión.
6. Al terminar: descargar Excel o sincronizar solo las seleccionadas.

## Reglas
- No modifica la foto original.
- No elimina IndexedDB.
- PANEL exige empresa; BANNER y PINTA no.
- La edición masiva administrativa queda fuera del flujo móvil.
- El Excel actual sigue siendo una salida operativa.
