# ONE SHOT v6.0 · CLASIFICACIÓN CONVERSACIONAL INTELIGENTE

- **Editar con ONE**: la foto queda siempre visible y el asistente pregunta campo por campo.
- Respuestas por **botones o voz**; comandos: siguiente, atrás, guardar, guardar y siguiente, silenciar, eliminar.
- **Identidad configurable**: nombre del asistente y nombre/apodo del usuario.
- **Mascota robot dentro de Editar** con estados de escucha, análisis, éxito y error.
- **Rescate de Evidencia no destructivo**: giro, formato vertical/horizontal/1:1, zoom y reposicionamiento. La foto original se conserva.
- Flujo guiado: marco → tipo → partido → candidato → cargo → proceso → tipo de elección → estado → cantidad de elementos → observación → resumen.
- Comandos globales nuevos: silenciar asistente, volver a hablar, ocultar mascota, solo locales partidarios, limpiar filtro y abrir clasificación guiada.
- Mantiene cámara segura 5.8.1, Permission Assistant, Territory UX, Smart Route y `oneshotEvidenceDB_v2`.

> ONE sugiere y guía; la validación final sigue siendo humana.
