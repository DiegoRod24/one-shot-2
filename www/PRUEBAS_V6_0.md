# PRUEBAS v6.0

1. Abrir una evidencia → **Editar con ONE** debe mostrar foto + robot.
2. Recorrer todas las preguntas tocando opciones y guardar.
3. Repetir usando voz: “es panel”, “siguiente”, “atrás”, “guardar y siguiente”.
4. Configuración: cambiar nombre de ONE y nombre de usuario; reabrir Editar.
5. Decir “silénciate” y comprobar que mantiene mensajes visuales.
6. Rescate: girar 90°, elegir vertical, mover/zoom y aplicar. Comprobar que el original sigue verificable y la versión marcada usa el ajuste.
7. Restaurar original desde Rescate.
8. Decir “muéstrame solo locales partidarios”.
9. Verificar que cámara frontal/trasera conserva el comportamiento 5.8.1.
10. Cerrar/reabrir y comprobar que evidencias siguen en `oneshotEvidenceDB_v2`.
